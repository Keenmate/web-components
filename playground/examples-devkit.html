DK07 · Highlighted code

A <kmwc-demo>'s code is highlighted at build time (Shiki, coloured by the --kmwc-code-* tokens). A hand-written .code-block opts in with data-language — html, js, ts, css, json, svelte, sh — when its code is plain escaped text:

<script>
    // Closed again by the modal's onclose.
    let isOpen = $state(false);
</script>

{#if isOpen}
    <Modal title="Settings" onclose={() => (isOpen = false)} />
{/if}
npm install --save-dev @keenmate/web-components-devkit

Both get a Copy button. Without data-language a block stays as written, with no button — it may be an output a script fills:

change → { isActive: true }
