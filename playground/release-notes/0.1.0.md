# Web Playground 0.1.0 — Release Notes

**Released:** 2026-10-12 · **Stable** (`npm install @keenmate/web-playground`)

These notes cover the **first release** of `<web-playground>`: there is no earlier version to upgrade from.

Devkit test bed — exercises the Vite preset, examples kit and CLI end-to-end. This first version ships the element, its CSS variables and the editor metadata (Custom Elements Manifest); later releases describe what changed and how to upgrade.

The exhaustive, per-change list is in
[`CHANGELOG.md`](https://github.com/keenmate/web-playground/blob/prod/CHANGELOG.md) (section
0.1.0); this document is the upgrade guide and the highlights.

## New features

### `<web-playground>`

`label` / `active` inputs, a `change` event with its `onChange` property twin, and the `--pg-*`
CSS variables listed in `component-variables.manifest.json`.
