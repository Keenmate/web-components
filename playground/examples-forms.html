FC01 · Text fields

Every text-like <input> has the control height, the input border and an accent focus border with a halo. A required field turns red once the user has left it invalid (:user-invalid), not while it starts empty.

FC02 · Selects and list boxes

A single <select> gets the kit's caret, drawn in the input icon colour so it follows the theme. multiple or size makes a list box: it grows with its rows and a selected option is tinted with the accent.

FC04 · Checkboxes

The native checkbox, redrawn with the contract's checkbox render method: the box scales with --base-checkbox-scale, the tick and the dash are --base-icon-check / --base-icon-indeterminate — the same glyph every Keenmate component draws.

FC08 · Buttons and fields in one row

Buttons, inputs and selects share --kmwc-control-height, so a row of them lines up — also in a page's own container, not just a .controls row.

FC09 · A demo form

Inside a .form-group a field takes the full row.

FC10 · Opting out

Every rule is zero-specificity (:where()), so any page or component rule wins. A light-DOM component that draws its own inputs, or a demo that needs the browser's controls, puts kmwc-native on the element or an ancestor.
